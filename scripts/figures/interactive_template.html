Choose a source pair or click a matrix cell, then move the slider. Click a match on the curve plot or a location in the distribution to select the nearest saved statistic for that pair. Keyboard users can use the pair menu, slider arrow keys and Previous / Next buttons.

Reading the display. Each source has one training curve with 45 noisy position observations. Curves are shown on the same 61-node interpolation grid used for state matching, so saved matched points lie on the displayed curves. Reliability downweighting is applied only to the global density, not again to source evidence. The shaded peak region is descriptive, not a confidence interval. Exploring this panel does not refit models or alter the selected group; no true source labels are used by these controls.
