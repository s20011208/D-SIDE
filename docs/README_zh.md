# D-SIDE 中文说明

D-SIDE 的全称是 **Distributional Selective Integration for Dynamics Estimation**，即基于统计量分布、面向动力学估计的选择性整合。这里的 distributional 指“依据统计量分布”，并非分布式计算。

每个来源只有一条带噪位置轨迹时，独立估计可能不稳定；把所有来源直接合并，又可能让不同机制相互干扰。本方法先利用同位置配对构造一维动力学统计量，根据整体分布形成来源间证据，再选择一个共同群体联合估计。群体之外的来源保留独立模型。

模型为 $X_g''+a_gX_g'=f_g(X_g)$。不同来源的阻尼和非线性函数可以不同，所以这里研究的是控制方程本身的动力学异质性。算法的发布版本只在整体分布中对证据不足的来源对降权，聚类连接分数不再额外降权；选中群体共享一个非参数函数，各来源分别估计阻尼。

## 已运行结果

| 实验 | 独立预测 MSE | D-SIDE MSE | 完全选对 | 负迁移 |
|---|---:|---:|---:|---:|
| 新阻尼、原初态、旧10种子 | 0.009016 | 0.007869 | 7/10 | 4/80 |
| 新阻尼、适配初态、旧10种子 | 0.007498 | 0.007941 | 4/10 | 33/80 |
| 新阻尼、适配初态、新20种子 | 0.006582 | 0.006935 | 6/20 | 59/160 |

旧10个种子属于已经看过的回顾性实验。新20个种子在本轮方案冻结后评估。主例有12.7%的平均预测误差改善，但适配初态方案失败；不能宣称已稳定解决负迁移。原初态下，不加分布降权的旧选择器与D-SIDE恰好给出了相同结果，因此该例不能证明降权规则自身的增量。

测试是同一来源在新初始条件下的短期自由模拟，每个方法均获得真实测试初始位置和速度，之后不输入未来真实状态。本发布没有完成真实数据应用，也没有给出新的统计理论或置信区间覆盖保证。
